# GBSA 통합 스마트 리마인더 & 출결·교육 자동화 시스템

본 시스템은 **출근 미인식 실시간 감시 엔진** 및 **교육 수료증 자동 OCR 교차 검증 & 리마인더**를 통합 제공하는 데모 웹 애플리케이션입니다.

---

## 🚀 주요 구현 기능 요약

### 1. 교육 수료 자동화 코어 시스템 (이미지 1 구현)
* **취합부서 (관리자)**
  * **1. 공지 등록 및 교육 건 생성**: 교육 과정명, 이수 기한(D-Day), 자동 리마인더 주기 설정 및 공문 OCR 자동 인식.
  * **개인별 Magic Link 자동 배포**: 전사 대상자 대상 고유 Magic Link(원클릭 전용 제출 링크) 일괄 발송 (SMTP).
  * **실시간 제출 대시보드 모니터링**: 부서별 수료율 집계, 미제출자 현황 실시간 모니터링.
  * **최종 결과물 원클릭 다운로드**: 최종 집계 엑셀(.csv) 및 수료증 일괄 ZIP 다운로드 지원.
* **임직원 (제출자)**
  * **2. 안내 메일 발송**: 개인별 고유 전용 링크(Magic Link)를 통해 **로그인 없이 즉시 접속**.
  * **3. 파일 업로드**: 수료증 PDF/이미지 드래그 & 드롭 업로드.
  * **즉시 제출 완료 확인**: 업로드 즉시 AI OCR이 성명, 교육명, 기한을 실시간 검증하여 합격 접수증 발급.
* **자동화 코어 시스템 (Core Automation)**
  * 수료증 파일 자동 검증 (OCR 이름·일자·과정명 대조)
  * 개인별 원클릭 제출 링크 발송 (SMTP)
  * 미제출자 자동 D-Day 리마인더 (D-7, D-3, D-1, D-Day)
  * 부서/개인별 상태 자동 집계

---

### 2. 에스원(S-1) 지문인식기 실시간 감시 엔진 (이미지 2 구현)
* **참여 주체**: 직원 (예: 09:00 출근자) ↔ 에스원 지문인식기 ↔ 실시간 감시 엔진 (FastAPI + APScheduler) ↔ 사내 메일 발송기 (Mock)
* **시나리오 1: 정상 출근 (08:55 지문 태그)**
  * 08:55 단말기 태그 성공 ➔ 엔진 기록 동기화 ➔ [정상 출근] 판정 ➔ 알림 발송 생략.
* **시나리오 2: 지문 미인식 / 기기 에러 (09:05 기준 감지)**
  * 09:00 출근자인데 09:05까지 지문 기록 없음 감지.
  * **출근 미인식 긴급 알림 트리거** ➔ 직원에게 🚨 `[긴급] 오늘 출근 지문이 인식되지 않았습니다. 기기를 다시 확인해 주세요!` 메일 즉시 도착.
  * 직원이 메일 확인 후 09:07 단말기 지문 재태그.
  * 감시 엔진이 09:07 태그를 인식하여 **[정상 인증]으로 즉시 전환**하고 추가 독촉 알림 자동 차단.
* **실시간 감시 엔진 콘솔**: 시뮬레이터 조작에 따라 터미널 로그가 실시간 출력되어 전체 백엔드 플로우를 시각적으로 확인 가능.
* **사내 메일 발송기 (Mock Inbox)**: 시스템에서 발송된 긴급 근태 경보 및 교육 Magic Link 메일 수신 확인 기능.
